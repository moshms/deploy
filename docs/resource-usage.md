# Замер ресурсов

## Методика

- Стенд: локальная Linux-машина, Docker 29, Compose v5. Это не VPS, поэтому абсолютные числа нужны только для сравнения вариантов между собой.
- Образы: `MC_TAG=stage10` (этапы 1–10).
- Библиотека: пустая, без фоновых заданий.
- Команда: `ENV_FILE=.env.example ./scripts/measure.sh`, один установившийся сэмпл `docker stats --no-stream` после 10 секунд простоя.
- Для повторного замера на VPS используйте `scripts/measure.sh`.

## Выводы

- Ядро укладывается примерно в 39 MiB RSS; worker и transcoder в простое добавляют около 6 MiB.
- Мониторинг — самая тяжёлая опциональная часть: Prometheus + Grafana + exporter добавляют около 450 MiB, в основном за счёт Grafana.
- Замер этапа 1 не сохранился, поэтому текущие числа фиксируем как новую базовую точку. Для повторного замера используйте `scripts/measure.sh` на целевом VPS.
